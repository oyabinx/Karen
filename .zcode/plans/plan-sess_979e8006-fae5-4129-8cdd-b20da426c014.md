# Dashboard Semua Role: Panel "Armada Hari Ini"

Ide sangat layak: dashboard pengurus sudah punya "Peminjaman Berjalan Hari Ini" (hanya status `dipinjam`, limit 6), tapi admin & pegawai tidak punya info armada sama sekali — padahal pegawai adalah peminta info terbanyak ("mobil A hari ini siapa yang pakai?"). Solusi: **satu partial bersama** menampilkan status seluruh armada hari ini (dipakai siapa + HP, di bengkel, armada event) di ketiga dashboard.

## 1. Controller — `DashboardController`
- Tambah private method `armadaHariIni(): array`:
  - **dipakai**: `Booking` `whereIn(status, ['dipinjam','menunggu_penggantian'])` + jendela hari ini (`start_date <= today`, `end_date >= today`), eager load `user.seksi.bidang` + `vehicle`, urut nama kendaraan. Konsisten dengan definisi "aktif" di AvailabilityService.
  - **bengkel**: `Maintenance` `status=terjadwal` yang mencakup hari ini, with `vehicle`.
  - **eventArmada**: `Event` `terjadwal` mencakup hari ini, with `vehicles` + `bidang` → flatten per unit.
  - Dedup unit (prioritas: dipakai > bengkel > event) supaya satu mobil tidak muncul dua baris.
- `index()` meneruskan `armadaHariIni` ke **ketiga** view (variabel terpisah dari `data`).
- Hapus `peminjamanHariIni` lama dari `pengurusData()` (digantikan panel baru).

## 2. Partial baru — `resources/views/dashboard/partials/armada-hari-ini.blade.php`
Section card pola existing (`bg-white rounded-xl border p-6`):
- Judul **"Armada Hari Ini"** + chip ringkas (n dipakai · n bengkel · n event).
- Baris per unit (pola 2-baris seperti section pengurus sekarang, mobile-friendly):
  - **Dipakai**: nama mobil + plat · peminjam (bidang) · **📞 no. HP sebagai link `tel:`** (muncul bila terisi) · "s.d. {tgl} · {tujuan}" · pill amber "menunggu pengganti" bila statusnya demikian.
  - **Bengkel**: 🔧 unit + "di bengkel s.d. {tgl}" · catatan singkat.
  - **Event**: unit + nama event · bidang · "s.d. {tgl}".
- Empty state: "Tidak ada armada yang dipakai hari ini." (nuansa hijau).

## 3. Penempatan di 3 view
- `dashboard/pegawai.blade.php`: section penuh setelah panel peminjaman aktif pribadi, sebelum "Riwayat Terakhir".
- `dashboard/admin.blade.php`: section penuh setelah baris kartu statistik, sebelum "Struktur Organisasi".
- `dashboard/pengurus.blade.php`: **ganti** section "Peminjaman Berjalan Hari Ini" lama dengan partial ini (kini ikut menampilkan menunggu-pengganti + HP, tanpa limit 6). Link "Semua peminjaman →" dipertahankan.
