# Plan: Skema Baru Anggaran — Menu Terpusat, Rincian Nota, Koefisien Dinamis, Realisasi Bulanan

## A. Menu Anggaran Terpusat (Pengurus)
- **Route**: `GET /pengurus/anggaran` → `BudgetOverviewController@index`
- **View**: `pengurus/anggaran/index.blade.php`
  - **Desktop**: tabel semua kendaraan × 4 pos (anggaran | realisasi | sisa per pos, merah bila minus); year picker header
  - **Mobile**: kartu per kendaraan — nama/plat + 4 chip pos dengan sisa anggaran (merah/hijau); scroll horizontal tabel ringkasan
- **Menu**: "Anggaran" di seksi Kendaraan sidebar; klik kendaraan → halaman anggaran per-kendaraan

## B. Rincian Nota — Teks + Nominal per Baris (MOBILE-FIRST)
- **Migrasi**: `maintenance_cost_details` (maintenance_cost_id FK cascade, description VARCHAR(255), amount DECIMAL(14,2), timestamps)
- **Model**: `MaintenanceCostDetail` + relasi hasMany dari MaintenanceCost
- **Form nota (`costs.blade.php`) — dirancang mobile-first**:
  - Setiap pos menjadi **section terpisah** (card) yang stack vertikal di mobile — bukan tabel horizontal
  - Nominal pos: input besar full-width dengan prefix Rp + pemisah ribuan live + hasil × koefisien di bawahnya (font besar, warna aksen)
  - Tombol **"+ Tambah Rincian"** (≥44px touch target) menambah baris berisi: description (textarea 1 baris auto-grow) + nominal (input Rp dengan pemisah ribuan)
  - Baris rincian punya tombol **"✕ Hapus"** (≥44px) di kanan
  - Semua opsional — pos dengan 0 rincian tetap valid
  - Desktop: grid 2 kolom (2 pos per baris); Mobile: 1 kolom stack
- **BudgetService::inputNota()**: terima `details[post][]` array; replace existing per pos (delete + recreate)
- **Tampilan rincian**: expandable di realisasi bulanan; ikut di kartu inventaris PDF & bend26

## C. Koefisien Pajak Configurable (Admin)
- **AppSettings**: `koefisien_pajak` (default 1.13, range 1.00–2.00, step 0.01)
- **Admin settings**: field "Koefisien Pajak" + note "hanya berlaku untuk nota baru"
- **BudgetService**: hapus konstanta; semua 1.13 hardcode di JS/view/CSV → baca dinamis `AppSettings::koefisienPajak()`
- **Nota lama**: taxed_amount TIDAK dihitung ulang; simpan `koefisien_used` pada maintenance_cost untuk jejak historis
- **Form nota JS**: live calc pakai nilai dinamis (bukan hardcoded 1.13) — ambil dari data attribute

## D. Halaman Realisasi Bulanan (Pengurus) — MOBILE-FRIENDLY
- **Route**: `GET /pengurus/realisasi-bulanan?bulan=YYYY-MM`
- **View**:
  - Month picker (default bulan berjalan, 12 bulan ke belakang)
  - **Desktop**: tabel detail + ringkasan per pos dengan progress bar
  - **Mobile**: kartu per nota (tanggal, mobil, bengkel, pos, total) — expandable untuk lihat rincian per baris; ringkasan pos sebagai 4 kartu horizontal scroll
  - **Rincian expandable** (Alpine.js `<details>` atau accordion)
  - **Export CSV** dengan rincian
- **Menu**: "Realisasi Bulanan" di seksi Monitoring sidebar

## E. Docs & Tests & Mobile QA
- **Docs**: product.md + anggaran_maintenance.md + structure.md
- **Tests**: rincian CRUD; koefisien dinamis (ubah → baru pakai nilai baru, lama tetap); realisasi bulanan; export
- **Mobile QA**: form nota di 360px — semua input ≥44px, stack 1 kolom, hasil ×koefisien terlihat tanpa scroll, tombol rincian mudah dijangkau jempol; realisasi bulanan kartu di mobile
